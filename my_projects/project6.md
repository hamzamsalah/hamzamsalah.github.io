## Project Overview
This course project uses regression analysis to identify factors that increase MLB game attendance and inform data-driven promotional strategies.

### Key Insights
- Promotions like bobbleheads boost attendance by ~15%.  
- Weather impacts: rain reduces crowds by ~10%.  
- Weekends see ~20% higher turnout.
