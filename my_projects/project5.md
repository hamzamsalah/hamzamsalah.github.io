### Project Overview
This database project supports hospital operations during pandemics by tracking patient and staff data securely.

#### Key Insights
- Normalized schema reduces redundancy and improves query speed.
- Views and procedures enable quick exposure reports.
- UI facilitates real-time updates for medical staff.
