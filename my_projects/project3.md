## Project Overview
This project forecasts monthly US retail sales (1992–2021) using an ARIMA model to predict post-COVID-19 trends, identifying pandemic-related dips and recovery patterns.

### Key Insights
- Achieved an RMSE of $52,207.
- Highlighted recovery patterns post-COVID-19.
